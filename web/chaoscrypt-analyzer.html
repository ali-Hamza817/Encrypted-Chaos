MS / PhD Thesis Instrument  ·  Supervisor: Dr. Ayesha Khalid

How much of an encrypted image can a neural network learn to read back — with no key?

Encrypted-Chaos is a research instrument for data-driven cryptanalysis. It builds plaintext–ciphertext datasets from a chaos-based image cipher, profiles that cipher with the classical security metrics, then trains CNN / U-Net models to reconstruct the plaintext from ciphertext alone — and reports how far they get.

What it is

A bench that attacks a cipher and grades the result

Classical cryptanalysis asks whether an algorithm can be broken with mathematics. This project asks a different question: can a model learn the weaknesses of a chaos-based encryption scheme directly from examples? The toolkit turns that question into a repeatable measurement.

Encrypt

Configurable chaos ciphers + an AES baseline

Logistic, 2D-logistic and Hénon maps driving pixel permutation and XOR-chained diffusion, with adjustable rounds and static / per-image keying. AES-256-CTR as the honest control.

Profile

The security metrics a reviewer expects

Shannon entropy, NPCR, UACI, adjacent-pixel correlation (H / V / D), histogram uniformity and key sensitivity — computed on the same cipher the model then attacks.

Attack

CNN and U-Net reconstruction models

Trained on known plaintext–ciphertext pairs to approximate the inverse transform. Scored on held-out ciphertexts with PSNR, SSIM and MSE.

Verdict

An Attack Risk rating, and why

Reconstruction fidelity is folded into LOW / MEDIUM / HIGH and attributed to specific scheme components through ablations — permutation vs diffusion, round count, keying mode.

How it works

One pipeline, two readouts

The same plaintext–ciphertext dataset feeds both the defensive profile and the offensive model. The two readouts are meant to be compared: a scheme can score almost perfectly on the classical metrics and still lose ground to the learned attack.

Measured results

One model, one budget, four ciphers

A single U-Net is trained under identical settings against each target. Success is scored as SSIM gain — how far the reconstruction beats the trivial “always predict the average image” floor. Gain near zero means the attack learned nothing.

Recovered images

Each strip is ciphertext (model input) / recovered (model output) / plaintext (ground truth), eight held-out samples.

Reading these numbers honestly. A high gain means the model recovered perceptual structure — not that the secret key was extracted. The diffusion-only static-key row is thoroughly recovered (SSIM gain +0.76): with no permutation, XOR-chained diffusion under a static key is a fixed position-dependent transform a shallow U-Net learns directly. Adding a global pixel permutation defeats this attack at this training budget — a component-attribution finding (RQ5), not proof the scheme is secure; a larger model, more pairs, or the cross-key setting are exactly what the thesis probes next. Per-image keying and AES show no recovery, as expected. Figures are from a short CPU budget on 32×32 procedural images — directional, not final.

Research questions

What the thesis actually answers

Reproducing the 2019 attack alone is not a contribution in 2026. The questions below move the work toward generalization — and toward whether the classical metrics predict resistance to data-driven attacks at all.

  1. Under a fixed key, can a CNN / U-Net trained on plaintext–ciphertext pairs reconstruct unseen plaintext images, and at what fidelity?

    same-key known-plaintext attack  ·  baseline

  2. Does an attack model trained on many keys generalize to ciphertext produced by an unseen key, with no retraining?

    ★ primary contribution  ·  cross-key generalization

  3. Does a model trained on one family of chaotic maps transfer to a different chaotic construction?

    ★ secondary contribution  ·  cross-algorithm transfer

  4. Under identical attack budgets, are chaos schemes more susceptible to learned cryptanalysis than AES-CTR on the same images?

    control  ·  fairness bound

  5. Which components drive attack success — permutation vs diffusion, round count, static vs per-image keying?

    ★ vulnerability attribution  ·  ablations

  6. How many known plaintext–ciphertext pairs are required to reach a target reconstruction quality?

    data-efficiency curve

Reproduce everything on this page

Pipeline

# one-time
pip install -r requirements.txt

# 60-second end-to-end check (no downloads)
python scripts/quickstart.py

# the four comparison runs on this page
python scripts/run_demo_suite.py

Interactive web app

python scripts/serve.py
# http://localhost:8000

Upload an image, pick a chaos scheme and key, read the cryptographic profile, then turn a trained model loose on the ciphertext — recovered image, SSIM gain and risk, side by side. Change the rounds or permutation and watch recovery fall.

Individual experiments: python scripts/run_experiment.py configs/rq2_cross_key.yaml. Each writes experiments/<name>/report.json with the config, scores and a sample grid.

Encrypted-Chaos — MVP for the thesis “Using ML to Attack Chaos-based Image Encryption”, supervised by Dr. Ayesha Khalid. Built as a Python package (chaoscrypt/) with CLI experiment runners, a FastAPI web app, and a pytest suite covering the cipher round-trips and metrics.

[1] He, Ming, Wang & Wang (2019). A deep learning based attack for the chaos-based image encryption. arXiv:1907.12245.
